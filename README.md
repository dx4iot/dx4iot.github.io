# dx4iot — Nishant Tiwari | Personal Portfolio

A cyberpunk-themed personal portfolio for **Nishant Tiwari (dx4iot)** — Security Researcher, Bug Bounty Hunter & Educator.

## 🗂️ File Structure

```
portfolio/
├── index.html   ← HTML structure & content
├── style.css    ← All styles, animations & responsive design
├── script.js    ← Cursor, Matrix rain, Three.js 3D scene, particles
└── README.md    ← This file
```

## 🚀 How to Run

Just open `index.html` in a browser — no build step required.

For best results use a live server (e.g. VS Code Live Server extension) so fonts and scripts load correctly.

## ✨ Features

- Custom animated cursor
- Matrix rain background (Canvas 2D)
- Three.js floating 3D skill objects
- Animated particle network background
- Scroll-reveal animations
- Responsive design with mobile hamburger menu
- Glitch text effect
- Terminal-style UI components

## 🛠️ Built With

- Vanilla HTML, CSS, JavaScript
- [Three.js r128](https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js)
- [Google Fonts](https://fonts.google.com/) — Orbitron, JetBrains Mono, Share Tech Mono
